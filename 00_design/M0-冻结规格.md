# M0 冻结规格（开工版）

> 日期：2026-11-03　对应主文档：v0.18　资源清单：`资源清单模板-v7.xlsx` / `资源清单模板-current.xlsx`
> **这是开工合同。与主文档旧章节冲突时，以本文为准。**

## 1. M0 范围（先做窄路径，不追求全量）

**一句话**：一条固定 30 秒 merge 模板、1 套主题、2 个关卡、2 个订单角色，1080×1920@60fps 可确定性出片。

### 必做（P0）

- 项目/模板：新建、打开、另存、复制变体。
- 棋盘编辑：7×9、放置/删除、锁定/网/泡/冰、随机铺盘、校验。
- 合成：同 `entity` + 同 `level` → `level+1`；支持不相邻合并（实机确认）。
- 生成器：点击产出、次数/冷却、稀有直出订单物品、棋盘满提示。
- 订单/角色：1–2 件需求、完成绿药丸、点击后物品飞向角色、角色消失、金币/星星、新角色新订单。
- 时间轴：事件模型 v2（见 §3）、预览、单步、撤销/重做。
- 出片：Godot Movie Maker 60fps、FFmpeg 转 MP4、确定性 hash。
- 资源：v7 manifest + 用途级别 + 渲染守卫。
- 校验：缺图/引用不存在/时间轴越界/订单不可达，**出片前阻断**。

### 不做（M0 明确不做）

- 主题编辑器 UI：主题用文件夹/`theme.json` 换，不做可视化换肤面板。
- 多语言切换 UI：文案键值表 P0；语言包切换 P1。
- 批量渲染、Web/HTML、音频、装修、完整经济、商店/广告 SDK、排行榜。
- 特效序列帧：M0 用静态占位 + Tween；序列帧 P1。
- 完整游戏数值平衡：广告只需要“看起来对”。

### 估算（重新基线）

| 范围 | 估算 |
|---|---|
| 窄路径 M0（本文） | **5–7 周**（1 人 + AI，不含美术接入/返工） |
| 主文档原全范围 | 8–12 周 |
| 原 3.5–4.5 周 | **作废**，只适用于“固定模板 + 单主题 + 窄路径演示” |

## 2. 数据模型 v2（`project.json`）

### 2.1 单一真相规则

1. **关卡顺序 = `levels` 数组顺序**；删除 `next` 指针（线性项目不需要第二真相）。
2. **实体统一**：`entities` 表定义 `kind`（`chip` / `generator` / `special` / `character`）；`board.slots` 用 `entity` 引用，不再混用 `chip`。
3. **生成器行为**放 `generators` 表，实体本身只在 `entities` 里声明。
4. **所有被引用的 ID 必须定义**；`CleanSet_Cb` 等不能只在生成器产出里出现。
5. **图标优先级**：`theme > project > default`；同一 ID 只允许一个最终来源。
6. **等级上限**：M0 统一 **10 级**；订单配置最高 11 级的关卡在 M0 先裁到 10 或标记为 P1。
7. **HUD**：`level / energy / energyTickSeconds / energyTickMode / coin / star / gem / exp` 全部显式。
8. **文案**：`locales` 键值表 P0；语言切换 UI P1。

## 3. 事件模型 v2（必须按这个写）

### 3.1 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 事件唯一 ID；用于锚点和排序 |
| `channel` | 是 | `sim`（游戏状态命令）/ `view`（镜头、文字、特效）/ `audio`（音频） |
| `type` | 是 | 事件类型；必须先注册 |
| `at` | 是 | 绝对秒数，或 `{"after": "e1", "offset": 0.3}` |
| `duration` | 否 | 表现/动画时长；模拟事件可为 0 |
| `order` | 否 | 同一时刻/同一锚点的排序，默认 0 |
| `track` | 否 | 编辑器轨道分组，不影响执行 |
| `payload` | 是 | 事件参数 |

### 3.2 排序规则（确定性）

1. 先把所有相对锚点解析成绝对时间；循环/缺失锚点直接报错。
2. 排序键：`at` → `channel` 优先级（sim=0, view=1, audio=2）→ `track` → `order` → `id`。
3. 同一事件序列 + 同一种子必须得到同一状态和同一帧。

### 3.3 禁止与约束

- **禁止 `wait` 事件**：用时间空隙或 `after/offset` 表达。
- **不再把游戏命令和表现事件混为一谈**：`channel` 必须显式。
- **新事件类型必须写代码/注册表**；“新增事件不改核心代码”不再作为承诺。
- 预览、单步、离线渲染共用同一个事件求值器。

### 3.4 最小事件集

- sim：`tap`、`drag`、`merge`、`deliver`、`order_claim`、`board_full`、`energy_tick`、`level_complete`、`level_next`
- view：`camera`、`text`、`highlight`、`select`、`hint`、`star_fly`、`coin_popup`、`character_leave`、`character_next`、`levelup`、`cta`、`transition`

## 4. 资源治理（版权边界）

### 4.1 三种用途级别

| usage | 含义 | 能否进主题/出片 |
|---|---|---|
| `REFERENCE_ONLY` | 原游戏 icon、UI 切图、PSD 导出、角色 | **禁止打包、禁止出片**；只用于观察/构图/尺寸参考 |
| `PLACEHOLDER` | Twemoji、PIL 生成、占位 UI | 仅当 `allow_placeholders=true` 时允许；渲染日志标注“占位” |
| `PRODUCTION` | 自绘、外包、明确授权素材 | 允许出片 |
| `TODO` | 音频等未补项 | 出片前阻断 |

### 4.2 Manifest 字段

`resource_manifest.json` / `.csv` 是唯一事实源；Excel 是只读视图。

| 字段 | 说明 |
|---|---|
| `id` | 资源 ID（与 project.json 对应） |
| `category` / `use` | 类别/用途 |
| `priority` | P0/P1/P2 |
| `status` | 参考图（禁止打包）/ 占位（可用）/ 可用 / 未补 |
| `usage` | REFERENCE_ONLY / PLACEHOLDER / PRODUCTION / TODO |
| `license` | 版权/许可/署名要求 |
| `file` | 当前引用路径 |
| `target_size` / `actual_size` | 建议尺寸 / 实际尺寸 |
| `fit` | `scale` / `crop` / `9-slice` / `redraw` |
| `nine_slice` | 九宫格边距（没有写 `n/a`） |
| `animation` | 序列帧数量/帧率/循环；静态写 `static` |
| `notes` | 备注 |

### 4.3 渲染守卫

- 加载资源时检查 `usage`；
- `REFERENCE_ONLY` → 直接报错，拒绝出片；
- `PLACEHOLDER` 且 `allow_placeholders=false` → 报错；
- `TODO` → 报错；
- 导出日志写入实际使用的资源 ID、usage、license 摘要。

### 4.4 版本与单一事实源

- 资源以 `resource_manifest.json` 为准；`资源清单模板-current.xlsx` 从 manifest 生成。
- 旧 v3–v6 只归档，不再手工改。
- CSV 使用 UTF-8 BOM；Excel 用户用 xlsx；脚本用 JSON/CSV。
- Excel 缩略图是浮动图片，排序会错位；**排序/筛选请用 manifest，不要依赖 xlsx 图片列**。

## 5. 编辑器 MVP（非程序员）

### 5.1 页面

```
项目/模板 → 棋盘编辑 → 订单/角色 → 主题映射 → 时间轴 → 校验 → 出片
```

- 项目页：新建/打开/另存/复制变体/模板。
- 棋盘页：7×9 网格、物品面板、格子属性、随机铺盘。
- 订单页：1–2 件需求、角色、奖励。
- 主题页：只读列出主题包和资源映射；不做可视化换肤。
- 时间轴页：轨道（sim/view/audio）、事件属性、相对锚点、预览、单步。
- 校验页：缺图、引用不存在、时间轴越界、订单不可达、usage 违规。

### 5.2 必须有

- 撤销/重做（至少 50 步）。
- 自动保存（每 30 秒/切换页面）。
- 异常恢复（崩溃后恢复草稿）。
- 校验失败给出“定位到具体格子/订单/事件”的可操作提示。
- 时间轴事件多时按 `channel` + `track` 分组折叠。

## 6. 出片流水线（M0 固定参数）

- 画布/窗口：1080×1920；Godot `window/size/viewport_width=1080`、`height=1920`；stretch `canvas_items`、aspect `keep`。
- Movie Maker：`--write-movie output.avi --fixed-fps 60 --quit-after 1800`；必须真实窗口，不可 `--headless`，录制中不得改窗口尺寸。
- 中间产物：优先 PNG 序列（1800 帧，原始约 15 GB）；预留 ≥20 GB 磁盘；支持清理/断点重跑。
- FFmpeg：工具内置或明确要求安装；版本锁定；参数模板；失败重试；`ffprobe` 校验分辨率/帧率/时长。
- 确定性：`ffmpeg -f framemd5` 对比两次输出；不再用“或肉眼无差异”。
- 性能基线：写明机器配置（CPU/GPU/内存）；5 分钟目标含 FFmpeg 转码；达不到就改目标，不改判据。

## 7. P0 验收（M0 完成定义）

- [ ] 一条固定 30 秒模板可完整出片：1080×1920 / 60fps / 1800 帧。
- [ ] 2 关可配置；完成第 1 关订单 → 过关 → 第 2 关。
- [ ] 订单完成：绿药丸 → 物品飞向角色 → 角色消失 → 金币/星星 → 新角色新订单。
- [ ] 生成器：点击产出、稀有直出订单物品、棋盘满提示。
- [ ] 选中提示：黄框 + 停留放大/靠近。
- [ ] 时间轴：绝对/相对锚点、同刻排序、预览/单步/渲染一致。
- [ ] 资源守卫：REFERENCE_ONLY 无法出片；PLACEHOLDER 需显式允许。
- [ ] 校验：缺图/越界/订单不可达/usage 违规在出片前阻断。
- [ ] 两次出片 `framemd5` 一致。
- [ ] 换 1 套主题（改 theme 文件夹）≤10 分钟，不改代码。

## 8. 旧文档冲突裁决

| 旧文档 | M0 裁决 |
|---|---|
| `levels` 数组顺序 + `next` | **只用数组顺序**；`next` 删除 |
| `chips.icons` vs theme `chip_icons` | **theme > project > default** |
| `board.slots.chip` + `generators` | 改为 `entity` + `kind`；`generators` 只存行为 |
| `CleanSet_Cb` 未定义 | 在 `entities` 中定义 |
| `maxLevel: 11` vs 素材 1–10 | **M0 封顶 10**；11 级订单裁掉/后置 |
| `hud` 缺 star/gem/exp | 补 `star / gem / exp` |
| 多语言 P1 vs FR9 P0 | 文案键值表 **P0**；语言切换 UI **P1** |
| “新增事件类型不改代码” | 降级为“已注册类型数据驱动；新类型写代码” |
| `meta.duration` + 时间轴末尾 | **只保留时间轴末尾** |
| 原游戏素材 vs 自绘/外包 | **REFERENCE_ONLY / PLACEHOLDER / PRODUCTION 三分** |
| v6 标题 v4、状态不同步、无 DV | v7/current 修正；manifest 为唯一事实源 |
| `obstacle_web` 已确认/待确认 | 以 PSD `常态/box1/蜘蛛网` 为 REFERENCE_ONLY 参考；M0 用占位 |
| 3.5–4.5 周 MVP | **窄路径 5–7 周；全范围 8–12 周** |

## 9. 实现顺序（建议按这个开工）

1. **Manifest + Schema 校验器**：读 `resource_manifest.json` + `project.json`，跑引用/usage/等级校验。
2. **Core 模拟 + 事件求值器**：board/merge/generator/order/level state；绝对/相对锚点；排序。
3. **棋盘 View**：7×9、slot、chip、选中、完成、障碍。
4. **订单/角色**：绿药丸、飞行动画、角色切换。
5. **时间轴 UI**：轨道、锚点、预览、单步、撤销/重做。
6. **出片**：Movie Maker + FFmpeg + framemd5 + 磁盘清理。
7. **主题映射**：theme 文件夹 + 资源守卫。
8. **校验/自动保存/异常恢复**。
9. **确定性/性能测试**：两次出片 hash、5 分钟基线。
