## 3. 今天做完的事（按能力，不按时间）

### 3.1 分辨率 / 录制目录

| 项 | 做法 |
|---|---|
| 玩 540×960 | `window/size/window_width_override=540`、`window_height_override=960` |
| 录真 1080×1920 | `window/stretch/mode="viewport"`（画布固定 1080，窗口只影响显示） |
| 一次录制一个目录 | `output/mov/<stamp>/`：`take_<stamp>.take.json`、`film.mp4`、`frames/`、`film.manifest.json` |
| 渲染帧不进编辑器 | `output/.gdignore`（687 个 `.import` 已清） |
| 抽帧不残留 | `render.sh` / `render_take.gd` 抽帧前清空 `frames/` |

### 3.2 成片托管实机组件

`movie_scene` 现在只做四件事：推进时钟、取快照、喂组件、画 overlay（手型光标）。四层分别是
`top_bar.gd`(0,0,1080×150) / `order_panel.gd`(0,210,1080×250) / `board_view.tscn`(0,0) / `bottom_bar.gd`(0,0)。

子节点画在父 `_draw()` 之后 → 顺序即层级：board → band → top → bottom → **fly** → **overlay**。

### 3.3 交付（claim）

- sim 交付**优先消耗"被点击的那一格"**，该格不匹配才回退行优先
- sim 返回 `taken`（真正被 `board.take` 的格子列表）
- 实机与成片都按 `taken` **逐枚**播飞行（2 行任务 → 2 枚，间隔 0.08s），起点取各自格心
- 金币 tick：9 → 11 → 13 → 14（3 次）；第 2 关 14 → 40 → 65
- 卡片 hold 1.55s（芯片 0.55s + 金币 1s）后才缩

### 3.4 拖动回放

- 录制端 60Hz 逐帧采样 `drag_trace`：`[t, from_x, from_y, pos_x, pos_y]`
- 成片 `TakeIo.drag_at()` 插值 → `board.set_drag_state()` → 带 ghost + 白角框
- `drag_chip_visible = true`（成片没有实机的 ghost 层，必须由棋盘自己画）

### 3.5 光标

- 实时：隐藏系统指针，自绘小手，**坐标用窗口像素 → 画布像素换算**（`_mouse_canvas_point()`）
- 成片：`FilmOverlay`（最后 add_child 的 Control）用自己的 canvas item 画手，
  父层画会被棋盘/订单带盖住
- 按下反馈：白环 0.25s（18→150px）+ 手压 0.86

### 3.6 规则修正 + 钉死

### 3.7 金币落点 = 顶栏图标（2026-11-09 下午，AGENTS §6.10）

- **问题**：成片金币螺旋落点写死 `(473.6, 49.6)`，实机读 `hud.counter_center() * 0.8`。
  两者都指向 `hud_view.gd` —— 而它在 §20.5 chrome 模式下是**隐藏**的（钱条由 `top_bar.gd` 画），
  所以金币一直飞向看不见的控件，比金币图标真实中心偏右 15px、偏上 6px。
- **修法**：`top_bar.gd` 新增 `fit_rect_for()`（纯几何）+ 量自贴图的 `COIN_ICON_RATIO` + `counter_center(key)`；
  实机 `game_screen._coin_anchor()`、成片 `movie_scene._hud_coin_anchor()` 都调它，落点不再有字面量。
- **三层验证**：单测黄金值 `(458.785, 54.841)`；成片帧实测图标中心 `(459.0, 56.5)`（差 1.7px）；
  A/B 出片（旧硬编码 vs 新锚点）飞行中段轨迹左移 ~7px，与 15.7px × lerp 比例吻合。
- 反向验证两处各一次，失败输出记在 AGENTS §6.10。
- **未收口**：`hud:star` / `hud:gem` 仍来自隐藏 hud_view（顶栏没有 star 控件）。

## 5. 现场事实锚点（改代码前先看这几条）

1. **`evaluator.step()` 的结果里没有 `payload`**，要读事件本体 `ev`。
2. **`_snap` 在 `_advance_to` 的事件循环里还是上一帧**：跨关查订单/关卡要用 `_evaluator.sim.level_index`。
3. **子节点顺序 = 绘制顺序**：任何"被盖住"的问题先看 `add_child` 的顺序。
4. **FlyAnim 的起点靠 `anchors["cell:x,y"]`**：不喂锚点就退回棋盘中心（曾经表现为"芯片从 2×2/2×3 飞出来"）。
5. **视图层不许自己数动画数量**：一律用 sim 返回的 `taken` / `spawn` 等真实数据。
6. **渲染写盘会覆盖成品**：验证短跑必须给 `--out output/render/...`。
7. **Godot 4 没有 `window/size/window_width` 这个键**（那是 Godot 3）；内嵌窗口无视 `get_window().size`，要改尺寸只能靠 override。
8. **飞行动画的落点问组件要，不许写死**：顶栏那套是 `top_bar.counter_center(key)`；
   之前写死的 `(473.6,49.6)` 是已隐藏的 `hud_view` 坐标（AGENTS §6.10）。
